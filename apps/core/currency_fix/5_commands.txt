КОМАНДЫ

1. Миграции — их две: добавление полей в core и удаление поля в services.

   python manage.py makemigrations core services
   python manage.py migrate

   Django спросит подтверждение на удаление столбца currency.
   Данные в нём не нужны — валюта теперь в настройках.

2. Проверьте, что кэш-таблица существует (иначе load() упадёт):

   python manage.py createcachetable

3. Запуск и настройка:

   python manage.py runserver

   /admin/ → Настройки сайта → блок «Цены» → выбрать валюту.

4. Проверка: откройте главную, посмотрите на блок услуг.
   Все цены должны быть в новой валюте разом.
